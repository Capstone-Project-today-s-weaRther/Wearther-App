# WEARther 화면 및 기능 흐름

1. **시작 화면** — `옷늘날씨 / Today’s WEARther`, Google 버튼. Google 동의 모달에서 취소 또는 계속을 누르면 `로그인을 건너뜁니다.` 안내 후 지역 설정으로 진입한다. 실제 OAuth는 호출하지 않는다.
2. **초기 위치 설정** — 현재 위치 사용 또는 지역 직접 선택. 선택 지역의 행정구역과 `zone`, `nx`, `ny`를 확보한다. 지역 확정 전에는 다음 단계로 이동하지 않는다.
3. **사전조사 1/3** — 성별 선택.
4. **사전조사 2/3** — 추위/더위 민감도 선택.
5. **사전조사 3/3** — 2자 이상 닉네임 입력.
6. **추천 준비 화면** — 닉네임과 함께 날씨, 권역 의상 이미지, 기온대 기준을 조회한다.
7. **환영 바텀시트** — 체감 성향 팀과 닉네임을 보여준 뒤 시작하기를 누르면 홈으로 이동한다.
8. **홈** — 날씨 요약 카드, 위치 변경 트리거, 해당 권역 상의 Top 4 거리 스타일, 오늘의 추천 착용 이미지.
9. **위치 변경** — 홈의 주소 또는 날씨 요약 카드 주소를 누르면 검색/현위치 바텀시트가 열린다. 지역을 확정하면 날씨와 추천 스냅샷을 다시 만든다.
10. **날씨 상세** — 현재 날씨, 시간대별 예보, 제공 범위 내 일별 예보.
11. **오늘의 추천** — 착용 이미지, 룩 제목/설명, 내 리뷰 요약, 리뷰 작성 버튼.
12. **리뷰 작성** — 추움/적당함/더움 중 하나를 필수 선택하고 추가 의견은 선택 입력한다. 의견을 입력하면 10자 이상, 최대 500자다.
13. **리뷰 완료** — 등록 후 `아니요`는 오늘의 추천으로, `마이페이지로`는 MY 화면으로 이동한다.
14. **MY / 작성한 리뷰** — 닉네임, 리뷰 건수, 리뷰별 룩 제목·날짜·체감 평가·선택 의견을 표시한다.

## 저장 범위

- 브라우저 로컬: 프로필(닉네임/성별/체감 성향), 진행 중 사전조사, 선택 지역, 일일 추천 스냅샷, 시연 리뷰 fallback.
- Supabase: `fashion_images`, `region_map`, `weather_clothing_map`, `region_adjust`, `outfit_feedback` 및 기존 RPC.
- KMA: 서버 경로 `/api/weather`에서만 호출. `KMA_SERVICE_KEY`는 `VITE_` 접두사 없이 서버 환경변수로 설정한다.

## 날씨 예보 범위

현재 KMA 단기예보 호출은 초단기실황과 동네예보를 이용한다. 동네예보 응답에서 제공되는 날짜까지만 실제 일별 값으로 표시하며, 7일 예보 전체를 보장하지 않는다. 키가 없는 로컬 시연 모드의 일별 값은 샘플 데이터다.
